                                                                                                                                                                                                          • 突破/升星：当伙伴达到特定等级上限后，需要消耗同名伙伴碎片或通用突破材料进行突破。每次突破不仅提升基础属性，还可能解锁新的技能或天赋。这是提升伙伴战力最直接有效的方式之一。

                                                                                                                                                                                                          2. 技能升级与觉醒

                                                                                                                                                                                                          • 技能升级：消耗技能书或金币，提升伙伴各项技能的等级。优先升级核心输出或辅助技能。
                                                                                                                                                                                                          • 技能觉醒：部分高稀有度伙伴在突破到一定阶段后，可进行技能觉醒，大幅强化原有技能效果，甚至改变技能机制。觉醒材料通常较为稀有，需策略性分配。

                                                                                                                                                                                                          3. 装备与圣物系统

                                                                                                                                                                                                          • 装备选择：为伙伴穿戴合适的装备（武器、防具、饰品等）。根据伙伴定位，选择增加攻击、防御、生命、暴击、速度等不同属性的装备。
                                                                                                                                                                                                          • 装备强化与精炼：消耗金币和强化石提升装备基础属性。精炼则能进一步提升装备的百分比属性或特殊词条。
                                                                                                                                                                                                          • 圣物/神器：部分游戏设有独立的圣物或神器系统，这些装备通常附带强大的套装效果或独特技能，是后期提升战力的重要手段。

                                                                                                                                                                                                          4. 羁绊与亲密度

                                                                                                                                                                                                          • 羁绊系统：特定伙伴之间存在羁绊关系，同时上阵或拥有这些伙伴，可以激活额外属性加成。这鼓励玩家收集并培养特定组合。
                                                                                                                                                                                                          • 亲密度/好感度：透过赠送礼物或互动，提升伙伴亲密度，不仅能解锁背景故事，还可能获得额外属性奖励或专属语音。

                                                                                                                                                                                                          5. 符文/宝石镶嵌

                                                                                                                                                                                                          • 符文/宝石：根据伙伴属性与定位，选择合适的符文或宝石进行镶嵌。例如，输出型伙伴偏向攻击、暴击，防御型伙伴偏向生命、防御、韧性。
                                                                                                                                                                                                          • 符文套装：收集特定数量的同类符文，激活强大的套装效果。
