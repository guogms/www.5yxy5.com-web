                                                                                                                                                                                                          1. 權重如何計算與顯示

                                                                                                                                                                                                          每個關卡都有其獨特的屬性權重組合。通常，關卡會明確標示出兩個主要屬性，例如「華麗：S、優雅：A」。這表示「華麗」屬性在該關卡中擁有最高的權重，其次是「優雅」。

                                                                                                                                                                                                          • S/A/B/C/F級別： 這些等級代表了該屬性在關卡中的重要程度。S級權重最高，F級最低（甚至可能為負權重）。
                                                                                                                                                                                                          • 隱藏權重： 除了明確標示的S/A屬性外，其餘屬性也並非毫無作用。它們通常擁有較低的「隱藏權重」，只是遊戲界面不直接顯示。這意味著即使是C級或F級的屬性，在某些情況下仍能提供少量分數，但主要還是要圍繞S/A級屬性進行搭配。
                                                                                                                                                                                                          • 權重比例： 實際的權重比例通常是一個數值，例如S級可能是1.0或1.2，A級是0.7或0.8，依此類推。這些數值決定了服裝屬性分數的最終加成。

                                                                                                                                                                                                          2. 不同關卡類型的權重特點

                                                                                                                                                                                                          不同類型的關卡，其屬性權重設置邏輯也略有不同：

                                                                                                                                                                                                          • 主線關卡： 通常權重設置較為固定，主要圍繞兩個S/A級屬性。是玩家熟悉權重機制的基本訓練場。
                                                                                                                                                                                                          • 競技場： 每個主題都有特定的五個屬性權重，且權重比例可能更為極端，例如某個屬性權重高達1.3，而另一個則為0.2。這要求玩家對主題屬性有更深入的理解和精準的搭配。
                                                                                                                                                                                                          • 聯盟委託： 類似競技場，有特定主題和權重。通常會結合聯盟成員的共同目標，需要玩家在有限的次數內打出高分。
                                                                                                                                                                                                          • 活動關卡： 權重設置多變，有時會出現意想不到的組合，考驗玩家的應變能力和服裝儲備。

                                                                                                                                                                                                          2. 配裝策略：優先級與平衡

                                                                                                                                                                                                          掌握了權重，接下來就是實際的配裝技巧：

                                                                                                                                                                                                          • 優先級原則：

                                                                                                                                                                                                            2. A級屬性次之： 在S級屬性滿足後，再考慮A級屬性。
                                                                                                                                                                                                            3. 避免負權重： 如果某個屬性是F級（負權重），盡量避免穿戴帶有該屬性高分的服裝，以免扣分。
                                                                                                                                                                                                            4. 平衡隱藏屬性： 在S/A級屬性得分相近時，可考慮其他隱藏權重較高的屬性，進行微調以達到更高分。
                                                                                                                                                                                                          • 單品屬性分析： 每件服裝都有其獨特的屬性組合。例如，一件裙子可能同時帶有「華麗」和「可愛」屬性。當「華麗」是S級，「可愛」是A級時，這件服裝的利用率就很高。
                                                                                                                                                                                                          • 套裝加成： 許多套裝不僅外觀精美，其單品屬性也經過精心設計，在特定主題下能發揮巨大優勢。但切記，盲目穿戴整套不一定能拿高分，仍需根據權重進行單品替換。

                                                                                                                                                                                                          • 誤區一：只看外觀不看屬性。 這是新手最常犯的錯誤。記住，這是一個搭配「比賽」，分數才是王道。

                                                                                                                                                                                                            • 替換策略： 準備多套備用服裝，在某些屬性權重不明顯或你的高分服裝庫不足時，進行靈活替換。
