                                                                                                  物理輸出系（遊俠、斬首、龍騎士）

                                                                                                  物理系職業的目標是最大化物理傷害，並根據情況選擇泛用或特化組合。

                                                                                                  • 頂尖泛用組合（MVP/副本）：
                                                                                                    • 雙刀/拳刃： 時間支配者卡片 + 汙染浪人武士卡片
                                                                                                      • 分析： 這套組合提供了極高的ATK%與技能後延遲減少，幾乎是所有物理職業的畢業首選。時間支配者卡片在提供高額ATK的同時，其副作用可被其他裝備或素質抵銷，效益極高。
                                                                                                    • 雙手劍/長矛： 深淵騎士卡片 + 塔奧群卡卡片
                                                                                                      • 分析： 經典不敗的組合。深淵騎士提供穩定的對BOSS增傷，而塔奧群卡在血量撐高後提供的ATK加成極為恐怖，是血牛型物理職業（如龍騎士）的首選。

                                                                                                      • 分析： 在玩家對戰中，生存與控制同樣重要。嗒妮小姐卡片的冰凍效果能有效控場，搭配種族減傷卡（如：紅蛙卡、獸人戰士長卡）能大幅提升存活率。

                                                                                                  魔法強攻系（咒術士、妖術師）

                                                                                                  魔法系的組合核心在於最大化MATK、減少詠唱時間以及針對特定屬性增傷。

                                                                                                  • 頂尖泛用組合：

                                                                                                      • 分析： 這套組合專為無視魔防（MDEF）而生。在當前版本，高階魔物與玩家的MDEF極高，無視MDEF屬性帶來的實際傷害提升遠超單純的MATK%加成。
                                                                                                  • 屬性特化組合：
                                                                                                    • 變異白色騎士卡片 + （對應屬性增傷卡，如：異變魚卡）
                                                                                                      • 分析： 針對特定副本或MVP，將屬性傷害最大化是最高效的策略。變異白色騎士卡片提供了基礎MATK與屬性增傷，再搭配另一張屬性卡，能打出毀滅性的傷害。
